# Principles of Research Data Management Architecture

This repository contains the source files for _Principles of Research Data Management Architecture_, a book that explains the technical foundations of modern Research Data Management (RDM).

## Contributing

Contributions are welcome. Please find [our guidelines here](CONTRIBUTING.md).

## Citing

Staiger, C., & Moopen, N. _Principles of Research Data Management Architecture_. https://github.com/rdm-foundations/rdm-architecture

## Contact

For feedback and suggestions, please use GitHub Issues following our [contributing guidelines](CONTRIBUTING.md). 
You can otherwise reach the authors by emailing c.staiger[at]uu.nl & n.moopen[at]uu.nl.
